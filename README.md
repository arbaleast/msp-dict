# 微软拼音增强词库

基于 rime-ice + rime-frost 合并转换的微软拼音自定义词典。

## 来源

- [iDvel/rime-ice](https://github.com/iDvel/rime-ice) - 雾凇拼音
- [gaboolic/rime-frost](https://github.com/gaboolic/rime-frost) - 白霜拼音

## 版本

| 文件 | 条目数 | 说明 |
|------|--------|------|
| `msp_full.txt` | 1,709,292 | 完整版（词频≥1）|
| `msp_freq10.txt` | 1,574,107 | 精简版（词频≥10）|
| `msp_freq50.txt` | 1,505,432 | 标准版（词频≥50）|
| `msp_freq100.txt` | 1,473,657 | 优质版（词频≥100）|
| `msp_freq500.txt` | 202,300 | 高频版（词频≥500）|

## 格式

`词语\t词频`，可直接导入微软拼音。

导入路径：**设置 → 时间和语言 → 拼音设置 → 词典 → 添加词典**
